# A+ Core 1 Study App

CompTIA A+ Core 1 (220-1201) study PWA for Modules 1–10.

## Updated build
- 814 unique questions
- Fixed the reported USB Power Delivery question wording
- Fixed the 1B troubleshooting question so it no longer asks to verify a solution that is already verified
- Improved the x86/x64 CPU architecture question wording
- Stronger within-quiz diversification to reduce repeated or near-duplicate questions
- Added **Specs & Standards** mode with focused recall practice for concrete speeds, lengths, frequencies, standards, ports, IP values, power, PoE, displays, CPU, virtualization, cloud, printer, USB, Ethernet, and Wi-Fi facts from the supplied source material
- Specs mode can be filtered by category and question count
- Existing objective coverage, explanations, randomization, stars, wrong questions, weak areas, challenges, final test, flashcards, LocalStorage progress, and PWA/offline support retained

## Source scope
The app uses the supplied CompTIA A+ Student Guide, Modules 1–10, together with the supplied official CompTIA A+ 220-1201 V15 Exam Objectives Document, Version 4.0. The Specs & Standards mode is restricted to facts supported by those supplied sources. PoE wattage questions remain supplemental standards detail because the official objectives name PoE standards but do not list the wattage table.
