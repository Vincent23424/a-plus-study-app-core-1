# A+ Core 1 Study App V3

Offline-friendly CompTIA A+ Core 1 study app covering Modules 1–10 from the supplied Student Guide.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then **Save**.
6. GitHub will provide the public Pages URL.

The app uses browser localStorage for progress, so each user/device keeps its own progress.
