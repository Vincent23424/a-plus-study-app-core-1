# A+ Core 1 Study App

A free CompTIA A+ Core 1 (220-1201) study PWA covering Modules 1–10.

## Current Build — V5.6

- **763 unique questions**
- Lesson and objective-aligned quizzes
- Final Test and Random Practice
- New Questions, Weak Areas, Wrong Questions and Starred Questions
- Flashcard Review
- Ports & Protocols
- **Specs & Standards** for speeds, lengths, frequencies, standards, ports, IP values, power, PoE, displays, CPU, virtualization, cloud, printers, USB, Ethernet and Wi-Fi
- 3-Module Challenge
- Randomized questions and answer choices
- Explanations after answering
- LocalStorage progress tracking
- PWA and offline support

## Source Scope

Based on the supplied:

- **CompTIA A+ Core 1 and Core 2 Student Guide — Modules 1–10**
- **CompTIA A+ 220-1201 V15 Exam Objectives, Version 4.0**

Specs & Standards uses facts supported by the supplied source material. PoE wattage is included as supplemental standards detail because the official objectives list the PoE standards without providing the wattage table.

## Technology

HTML, CSS, JavaScript, LocalStorage, Service Worker, Web App Manifest and GitHub Pages.

Built with **AI-assisted development** as a personal CompTIA A+ study project.
