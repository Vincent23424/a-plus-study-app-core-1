A+ Core 1 Study App V3
Offline-friendly CompTIA A+ Core 1 study app covering Modules 1–10 from the supplied Student Guide.

GitHub Pages
Create a new GitHub repository.
Upload index.html and this README.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select main and / (root), then Save.
GitHub will provide the public Pages URL.
The app uses browser localStorage for progress, so each user/device keeps its own progress.
