# A+ Core 1 Study App 220 1201

Static GitHub Pages/PWA study app for CompTIA A+ Core 1 Modules 1–10.

- English UI
- Questions from the supplied Student Guide content only
- 504-question bank in this version
- Module and lesson quizzes
- Final Test
- Wrong Questions
- New Questions
- Weak Areas
- Flashcard Review
- Local progress tracking
- PWA/offline caching after first successful load

## GitHub Pages
Upload the contents of this folder to the repository root and publish `main` / `/ (root)` with GitHub Pages.

## iPhone
Open the HTTPS GitHub Pages URL in Safari, then Share → Add to Home Screen.
